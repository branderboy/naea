# Growth + Distribution Matrix — EA Advocate

Real growth comes from matching each growth metric to the single (or paired) lever that actually moves it. Don't run everything at once — run the right trigger for the metric you're trying to push.

## The matrix

| Growth metric | Trigger type | Channel / Tool | Specific play | Why this lever (and not another) |
|---|---|---|---|---|
| **Reach** (net-new listeners per episode) | **Earned** + **Owned** (paired) | (Earned) Press pitch to Accounting Today, CPA Practice Advisor, Tax Notes / (Owned) NAEA Facebook page | Pitch each episode as a news angle ("IRS just changed X — here's what EAs need to know") AND post the same hook as a native FB video clip with episode link in first comment | Earned gives third-party authority + LLM-trainable citations; Owned gives same-day volume to a warm audience. Running them in parallel on the same episode hook compounds — the earned link gets shared by the FB audience, which signals engagement back to the publisher. |
| **Podcast ranking** (Apple / Spotify chart position) | **Single trigger: subscriber + review velocity in a 7-day window** | Email to NAEA member list with a dated CTA | One email per launch: "Subscribe + rate by Friday" — direct deep links to Apple Podcasts subscribe and review screens | Apple and Spotify weight *velocity*, not totals. One concentrated push beats a slow drip. Don't dilute with a second trigger — pick the launch window and hit it hard. |
| **Subscribers** (email list → podcast subscribers) | **Owned automation** | Parot automation flow, fired after the member list is built out | Drip: Day 0 welcome + latest episode → Day 3 "the 3 most-played episodes" → Day 7 "subscribe in your app" with platform deep links → Day 14 re-engagement | Parot handles the sequencing once; conversion from email subscriber → podcast subscriber is the cheapest growth lever you have because the audience is already opted in. |
| **Average listen time** (completion rate — the Apple/Spotify ranking input) | **On-asset trigger** | Chapter markers inside the episode itself (Apple Podcasts, Spotify, Overcast all read them) | Add 4–7 chapter markers per episode with keyword-loaded titles. Promote "jump to the section you care about" in the show notes. | Listeners who skip into a chapter complete more of the episode than listeners who drop off in the intro. Completion rate is the single biggest signal feeding the platform ranking algorithm — and it's the input you can change without changing the content. |
| **Downloads** (raw discoverability volume) | **Single trigger: directory presence** | Listen Notes, Podchaser, Goodpods | Submit full show with complete metadata, host bio, category tags, and `sameAs` cross-links. Claim all three profiles. | These are the aggregators every podcast app, SEO crawler, and LLM pulls from. Missing from any one of them is a permanent download leak. One afternoon of work, compounds forever. |
| **LLM citations / "best podcast" SEO** (the highest-leverage discovery channel in 2026) | **Earned via guest post** | "Best tax podcasts" / "best podcasts for accountants" roundup posts on accounting + finance blogs | Pitch yourself into existing roundups; offer a guest post that *is* a roundup (with EA Advocate included alongside 4–5 credible peers) | When someone asks ChatGPT or Claude "best podcasts for tax professionals," the model answers from listicles it saw during training. Getting cited in those listicles is how the LLM learns the show exists. This is the single highest-leverage SEO play right now — one good roundup placement outperforms a year of episode-page SEO. |
| **Re-engagement** (lapsed listeners / silent NAEA members) | **Owned email** | NAEA agent email list | "Just in case you missed this" send — bundle the 3 best recent episodes with a one-line hook each. Cadence: monthly. | Most of your existing list never opened the launch email. A second, lower-pressure touch with curated highlights recovers 10–20% of misses without burning the list. |

## How to read this

- **Two triggers (Earned + Owned) only for Reach.** Reach is the one metric where stacking channels actually compounds, because the earned placement and the owned post amplify each other.
- **Every other row uses one trigger.** Pick the lever, run it hard, measure it. Don't blur the attribution.
- **Order of operations matters.** Build the email list → fire Parot → that lifts subscribers → which lifts ranking velocity → which lifts directory placement weight → which feeds LLM listicles. Skipping a step doesn't break the chain, but the leverage drops.

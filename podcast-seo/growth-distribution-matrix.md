# Growth + Distribution Matrix — EA Advocate

| # | Goal | Real Strategy |
|---|---|---|
| 1 | **Distribution / Reach Growth** | Push every episode through two channels at once: earned (news and pitches) and owned (Facebook). |
| 2 | **Podcast Ranking** | Apple ranks shows on five signals — download velocity, completion rate, subscriber count, review count, and recency. The fastest signal to move is review count, so send emails asking listeners to leave a review. |
| 3 | **Subscribers** | Once the list is built, use Pardot to run an automation flow against it. |
| 4 | **Average Listen Time** | Add chapter markers to each episode. To drive downloads, list the show on Listen Notes, Podchaser, and Goodpods. The biggest SEO lever is landing in "best tax podcasts" roundups — LLMs cite those lists when asked for podcast recommendations, so being on them is how the LLM learns the show exists. Also send "just in case you missed this" emails to the agent list. |

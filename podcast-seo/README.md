# Podcast SEO + GEO Playbook — EA Advocate

Three reinforcing layers: on-podcast optimization, website/GEO, and backlink production for LLM citation.

## Files in this folder

- `seo-checklist.md` — week-by-week tactical checklist
- `geo-strategy.md` — how to get cited by ChatGPT / Claude / Perplexity
- `templates/episode-page.html` — drop-in episode page template with full schema markup
- `templates/llms.txt` — root-level file telling LLMs what this site is and what to cite
- `templates/llms-full.txt` — expanded version with key facts about NAEA / EA Advocate
- `outreach/podcast-directory-list.md` — 40+ directories to submit to
- `outreach/guest-pitch-template.md` — email template for booking guests + landing backlinks
- `outreach/listicle-pitch-template.md` — pitch template for "best podcasts" roundups

## Quick start

1. Pick one episode. Apply `episode-page.html` template to it. Get full transcript.
2. Submit show to all directories in `outreach/podcast-directory-list.md` (one afternoon of work).
3. Add `llms.txt` + `llms-full.txt` to site root.
4. Send 5 guest pitches per week using `outreach/guest-pitch-template.md`.
5. Send 10 listicle pitches per week using `outreach/listicle-pitch-template.md`.

After 90 days you should see: organic episode page traffic up 3–5x, first LLM citations appearing, top-10 podcast directory ranks for "enrolled agent" niche.
